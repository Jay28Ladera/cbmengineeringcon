  1. Make sure the machine has internet (Ethernet or Wi-Fi) and the right date and time.
  2. Save. Within a minute it shows here as waiting for approval.
  3. Approve it and give it a name (e.g. "Cebu office"). Its stored punches start coming in.
  4. Under Employees, put each person's machine User ID in Biometric ID, or link them from Unmatched IDs.
Older machines without an HTTPS option can't connect to an HTTPS-only site. For those, export the logs to a USB drive (Data Mgt. › Download › Attendance) and upload the file under Time Logs.
