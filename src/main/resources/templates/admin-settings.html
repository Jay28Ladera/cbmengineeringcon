Document numbering

Documents are numbered PREFIX-YEAR-0001 and start again at 0001 each January. If you are moving over from manual or other books mid-year, set where this year continues (for example, the last PO on paper was 150 → next 151). A number can't go back below one already issued, so there are never duplicates. Quotations (Q-000123) and job orders (JO-000123) follow the record number and can't be changed.
