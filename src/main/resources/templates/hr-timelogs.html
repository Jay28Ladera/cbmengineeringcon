Upload time logs

The attendance file from the machine or its software.

  • From the machine's USB: Data Mgt. › Download › Attendance — the …attlog.dat file.
  • From ZKTeco software (ZKTime, ZKBio, Attendance Management): export the attendance logs to Excel or CSV.
  • The file needs each punch's user ID and date/time. Punches already saved are skipped, so uploading the same file twice is safe.
